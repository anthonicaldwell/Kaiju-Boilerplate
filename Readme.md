# Kaiju Boilerplate

## Summary

A basic application framework written in C++20 utilizing SDL2 and OpenGL for display and events. This application has zero AI generated code, but AI assistance was used for code reference.

## Dependancies

- SDL2
- OpenGL
- GLEW

## How-to Build

1 ) Navigate to the Project directory.

```
cd Project
```

2 ) Install dependencies.

```
./Scripts/InstallDeps.sh
```

3 ) Run Make.

```
make
```
## Notes

You can place files anywhere in the source tree and they will automatically compile into the binary, assuming they are error free.
